Step 2 of 3: create the server

Do this within 1 hour. The block below already contains your one-time code. You do not edit anything.

Press and hold inside the box below, tap Select All, then tap Copy.

  1. Open console.hetzner.com and go into the project you used last time.
  2. Delete the old server ubuntu-4gb-hel1-3 first (open it, tap Delete). It never set up, and deleting it stops its charge.
  3. Tap Create Server.
  4. Location: any. Image: Ubuntu 24.04. Type: Shared vCPU, Arm64, CAX11. If CAX11 is not offered, pick CX23 under x86.
  5. SSH keys: leave empty.
  6. Firewalls: if a firewall is listed, tick it. If none is listed, skip this.
  7. Cloud config: the box is empty. Tap inside it and paste. Do not change anything.
  8. Tap Create & Buy now.

Step 3 of 3: check, then install

  1. Wait 2 minutes. Open the new server and tap the Console icon (top right, looks like >_). Do not type anything.
  2. You should see lines like G1 SETUP: step 1 of 6, counting up to step 6. That means it is working. If you see only a login: prompt after 5 minutes, stop and tell me.
  3. Within 15 minutes a line appears that starts with GATE-ATTEST app_id=. It repeats every 30 seconds.
  4. If instead you see a line starting with G1 FAILED, stop and send a screenshot of it. Do not install anything.
  5. In GitHub, open Vandelay-Org Settings, Developer settings, GitHub Apps, then the new App. Check its App ID equals the app_id number on the console, and that it lists exactly one private key whose fingerprint matches the key_fingerprint on the console.
  6. Only if both match: tap Install App, choose Vandelay-Org, and confirm.

That is everything. Reply "done" and the rest is automatic.
