Gate server setup: step 1 of 3

Sign in to github.com in this browser first, then tap the button.

  1. Any retry starts again at step 1; GitHub codes expire after one hour.
  2. GitHub opens a page titled Create GitHub App for Vandelay-Org. Check that the only organization permission listed is Self-hosted runners: Read and write.
  3. Tap Create GitHub App. If GitHub says the name is taken, add a number to the end of the name and tap it again.
  4. You come back to a page here showing a ready-made block with a Copy button. That is step 2.

Do not install the App yet. That is step 3, after the server shows its check line.
